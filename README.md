
# 🥊 UFC ALERT
### 원하는 경기만, 놓치지 않게

Python 기반 UFC 실시간 경기 맞춤 알림 서비스

---

## 📌 프로젝트 소개

UFC ALERT는 사용자가 관심 있는 UFC 경기를 선택하면,
실제 경기 진행 상황을 분석하여 해당 경기의 시작이
가까워졌을 때 맞춤형 알림을 제공하는 서비스입니다.

UFC 경기는 앞선 경기의 종료 시간에 따라
다음 경기의 실제 시작 시간이 달라지는 특징이 있습니다.

기존의 예정 시간 중심 알림과 달리,
UFC ALERT는 직전 경기의 종료 상태를 기준으로
사용자가 원하는 경기의 시작 임박 알림을
전달하는 것을 목표로 합니다.

또한 최신 UFC 대회 일정과 대진표를 자동으로 갱신하여
새롭게 발표된 경기와 변경된 대진 정보를
사용자가 편리하게 확인할 수 있도록 합니다.

## ⚙️ 주요 기능

### 1. UFC 경기 일정 자동 업데이트

- 새로운 UFC 대회 일정 자동 확인
- 대회별 날짜 및 장소 정보 확인
- 선수 대진표 자동 갱신
- 변경된 대회 일정 반영
- 한국시간(KST) 기준 경기 일정 제공
- 다음 UFC 대회 일정 미리보기

### 2. UFC 경기 목록 확인

사용자는 UFC 대회별 경기 일정과
선수 대진 정보를 확인할 수 있습니다.

- 초기 예선(Early Prelims)
- 예선 카드(Prelims)
- 메인 카드(Main Card)
- 코메인 이벤트(Co-Main Event)
- 메인 이벤트(Main Event)

메인 이벤트와 코메인 이벤트는
일반적으로 대회 후반부에 진행됩니다.

메인 카드 시작 시간은 확인할 수 있지만,
개별 경기의 실제 시작 시간은
앞선 경기 진행 상황에 따라 달라집니다.

### 3. 관심 경기 선택

사용자는 UFC 대진표에서
원하는 경기만 선택할 수 있습니다.

- 관심 선수 및 경기 선택
- 경기별 상세 정보 확인
- 여러 경기 동시 선택
- 선택한 경기 알림 일괄 등록
- 불필요한 경기 알림 제외

### 4. 맞춤 알림 설정

선택한 경기의 시작이 가까워지면
사용자에게 맞춤형 알림을 제공합니다.

- 경기별 알림 ON/OFF
- 직전 경기 진행 상태 확인
- 직전 경기 종료 시 알림 조건 판단
- 관심 경기 시작 임박 알림
- 동일 조건 중복 알림 방지

예시:

코메인 이벤트 진행 중
→ 코메인 이벤트 종료
→ 메인 이벤트 시작 임박 판단
→ 사용자 맞춤 알림 발송

### 5. 내 알림 관리

사용자가 등록한 UFC 경기 알림을
한 화면에서 관리할 수 있습니다.

- 등록된 경기 알림 목록 확인
- 활성화된 알림과 비활성화된 알림 구분
- 경기별 알림 켜기 및 끄기
- 알림 해제 및 재등록
- 이미 발송된 알림의 중복 발송 방지

### 6. 알림 수신

선택한 경기의 알림 조건이 충족되면
사용자의 휴대전화에 경기 시작 임박 알림을 제공합니다.

알림 표시 내용:

- UFC 대회 이름
- 선택한 경기의 선수 정보
- 직전 경기 종료 상태
- 경기 시작 임박 안내

알림을 선택하면
해당 경기 상세 화면으로 이동합니다.

※ 실제 모바일 푸시 알림은 향후 구현 기능입니다.

## 🔄 서비스 동작 원리

UFC ALERT는 경기 정보 수집부터
맞춤형 알림 전달까지 다음 과정으로 동작합니다.

### STEP 1. 경기 데이터 수집

UFC 대회 일정 및 선수 대진 정보를 수집합니다.

### STEP 2. 경기 일정 자동 갱신

새로운 대회 및 변경된 대진 정보를 확인하고
최신 경기 목록에 반영합니다.

### STEP 3. 사용자 관심 경기 확인

사용자가 선택한 UFC 경기를 확인하고
알림 설정 상태를 조회합니다.

### STEP 4. 경기 진행 상태 판단

선택한 경기의 직전 경기 진행 상태를 확인합니다.

### STEP 5. 알림 조건 비교

직전 경기가 종료되고
사용자 알림이 활성화되어 있는지 판단합니다.

### STEP 6. 맞춤 알림 발송

조건을 충족한 사용자에게
경기 시작 임박 알림을 제공합니다.

### STEP 7. 사용자 알림 확인

사용자는 알림을 통해
경기 시작이 가까워졌음을 확인하고
해당 경기 상세 화면으로 이동합니다.

### 자동 업데이트 검증 항목

- [ ] README.md 자동 갱신

### 시연 예시

```python
# UFC 경기 진행 상태 시뮬레이션

previous_fight_status = "진행 중"
notification_enabled = True
notification_sent = False

# 직전 경기 종료 상황
previous_fight_status = "종료"

if (
    previous_fight_status == "종료"
    and notification_enabled
    and not notification_sent
):
    print("🥊 UFC ALERT")
    print("선택한 경기의 시작이 임박했습니다!")
    notification_sent = True
```
