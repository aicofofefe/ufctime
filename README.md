# 🥊 UFC ALERT
### 원하는 경기만, 놓치지 않게

Python 기반 UFC 실시간 경기 맞춤 알림 서비스

## 📌 프로젝트 소개

UFC ALERT는 사용자가 관심 있는 UFC 경기를 선택하면,
경기 진행 상황을 분석하여 해당 경기의 시작이 가까워졌을 때
맞춤형 알림을 제공하는 서비스입니다.

UFC 경기는 앞선 경기의 종료 시간에 따라 다음 경기의
실제 시작 시간이 달라지는 특징이 있습니다.

기존의 예정 시간 중심 알림과 달리,
UFC ALERT는 직전 경기의 종료 상태를 기준으로
사용자에게 경기 시작 임박 알림을 전달하는 것을 목표로 합니다.

## 🎯 프로젝트 목표

- 관심 있는 UFC 경기만 선택하여 알림 등록
- UFC 경기 일정 및 대진표 확인
- 경기 진행 상태에 따른 알림 조건 판단
- 원하는 경기의 시작 임박 알림 제공
- 경기별 알림 활성화 및 비활성화
- 불필요한 중복 알림 방지

## ⚙️ 주요 기능

### 1. UFC 경기 목록 확인
- UFC 대회 일정 확인
- 메인 이벤트 및 코메인 이벤트 확인
- 초기 예선, 예선, 메인 카드 구분
- 다음 대회 일정 미리보기

### 2. 관심 경기 선택
- 원하는 UFC 경기 선택
- 선수별 대진 정보 확인
- 여러 경기의 알림 일괄 등록
- 선택한 경기 상세 정보 확인

### 3. 맞춤 알림 설정
- 경기별 알림 ON/OFF 설정
- 직전 경기 종료 시 알림 조건 충족
- 경기 시작 임박 알림 제공
- 동일 조건의 중복 알림 방지

### 4. 내 알림 관리
- 등록된 경기 알림 목록 확인
- 활성화된 알림과 비활성화된 알림 구분
- 경기별 알림 해제 및 재설정

### 5. 알림 수신
- 경기 시작 임박 알림 표시
- 선택한 경기의 선수 정보 제공
- 알림 선택 시 경기 상세 화면으로 이동

## 💡 사용 시나리오

### STEP 1. 경기 선택
사용자가 UFC 경기 목록에서 관심 있는 경기를 선택합니다.

### STEP 2. 알림 등록
선택한 경기의 시작 임박 알림을 활성화합니다.

### STEP 3. 경기 상태 확인
서비스에서 직전 경기의 진행 상태를 확인합니다.

### STEP 4. 알림 조건 충족
직전 경기가 종료되면 알림 조건을 판단합니다.

### STEP 5. 알림 발송
알림이 활성화된 사용자에게 경기 시작 임박 알림을 제공합니다.

## 🧪 MVP 구현 및 검증

본 프로젝트는 초기 MVP 단계로,
실시간 경기 데이터를 연결하기 전에
가상 경기 데이터를 활용하여 핵심 기능을 검증합니다.

### MVP 검증 항목

- [ ] 사용자가 관심 경기를 선택할 수 있는가?
- [ ] 선택한 경기의 알림이 정상적으로 등록되는가?
- [ ] 경기 상태가 변경되면 이를 감지하는가?
- [ ] 직전 경기 종료 시 알림 조건이 충족되는가?
- [ ] 알림이 중복 발송되지 않는가?
- [ ] 알림을 해제한 사용자에게 발송되지 않는가?
- [ ] 사용자가 등록된 알림을 관리할 수 있는가?
